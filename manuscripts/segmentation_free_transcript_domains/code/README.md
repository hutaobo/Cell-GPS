# Code

This folder contains the current working scripts for the manuscript package.

- `atera_breast_disim_coste_benchmark.py`: full-gene di-sim and selected-gene COSTE benchmark.
- `atera_breast_cellfree_transcript_pipeline.py`: earlier cell-free transcript-grid prototype.
- `atera_breast_transcript_point_histoseg.py`: corrected no-grid transcript-point HistoSeg pipeline.
- `atera_breast_point_vs_cell_histoseg_comparison.py`: after-the-fact comparison between transcript-point and cell-based COSTE-HistoSeg domains.
- `atera_breast_nature_pathology_figures.py`: Nature-style pathology explanation figures using official H&E alignment.

The primary manuscript claim should rely on `atera_breast_transcript_point_histoseg.py`, not the older grid prototype.
